BUNNY'S SECRET WEBSITE ♡

Files:
- index.html — the whole website. No libraries, no account, no payment.

How to use:
1. Open index.html in a browser to preview it.
2. Send the file to Bunny if she knows how to open HTML files, or publish it free using GitHub Pages / Netlify Drop.
3. For GitHub Pages: create a GitHub account, create a public repository, upload index.html, then open Settings → Pages and enable deployment from the main branch. GitHub's interface may change.
4. You can edit the messages directly in index.html with any text editor. Search for "My baby" or "Bunny" to personalize it further.

Important:
- This page is fully client-side and does not collect, transmit, or save messages.
- The message box only displays the typed message temporarily on the current page.
- No external fonts, images, trackers, or paid services are used.
